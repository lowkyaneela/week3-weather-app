
# Weather App

## Project Description
This is a simple and responsive Weather App developed using HTML, CSS, and JavaScript. It allows users to check current weather information for different cities using the OpenWeather API.

## Features
- Search weather by city name
- Display current temperature in Celsius
- Show weather conditions and weather icons
- Display humidity and wind speed
- Responsive and user-friendly interface
- Error handling for invalid city names and API errors

## Technologies Used
- HTML5
- CSS3
- JavaScript
- OpenWeather API

## Project Structure

weather-app/
│
└── index.html

## How to Run
1. Clone or download this repository.
2. Open index.html in VS Code.
3. Get an API key from https://openweathermap.org/api
4. Open index.html and replace YOUR_API_KEY with your own OpenWeather API key.
5. Save the file and run it using Live Server.

## API Configuration

Replace the API key placeholder in the JavaScript code:

const API_KEY = "YOUR_API_KEY";

Get your API key from OpenWeather:
https://home.openweathermap.org/api_keys

Do not share your personal API key publicly.
